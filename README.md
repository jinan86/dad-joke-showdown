# Dad Joke Showdown

Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) competition on make.fun.

## The joke

> I asked the salt why it always sits next to the pepper at dinner, and it said, 'Because we're the seasoned regulars here, and someone has to keep this table from getting bland.'

## How to run

```bash
python3 main.py
```

The program writes the joke above to `/output/entry.txt`. It is fully
self-contained and deterministic: no randomness, no network, no environment
variables, and no files read from outside this repository — the joke string
is written directly in `main.py`, so every run produces byte-identical output.
